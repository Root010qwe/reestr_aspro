# Реестр документов — мини-приложение Аспро.Cloud

Свод по договорам («кто кому сколько должен»), реестр с фильтрами и список того, что проверить.
Читает пользовательский список «Реестр документов» (id 8) с правами текущего пользователя; сам ничего не пишет.

## Файлы

- `index.html` — интерфейс (вкладки: свод, реестр, «что проверить»; `#registry`, `#alerts` открывают вкладку по ссылке)
- `js/model.js` — свод и тревоги, без DOM; `js/config.js` — коды полей и вариантов списка 8
- `js/portal.js` — доступ к порталу (OAuth из frame SDK, запасной путь через сессию), как в doc_aspro
- `manifest.json` — права `customlists: read`, пункт в главном меню
- `tests/model.test.mjs` — `node app/tests/model.test.mjs`: свод должен сходиться с актами сверки

## Развёртывание

1. Выложить папку `app/` на любой HTTPS-хостинг статики (как doc_aspro — GitHub Pages).
2. В `manifest.json` заменить `https://ВАШ-АДРЕС/reestr/index.html` на реальный адрес.
3. Аспро.Cloud → Приложения → Разработчикам → создать приложение из `manifest.json`, установить.
4. Выдать доступ к списку «Реестр документов» (настройки списка → Пользователи) тем, кто будет смотреть свод.

Локальная проверка без портала: `index.html?demo=<файл.json>` — выгрузка элементов списка в формате API.

## Правила свода

- **Закрыто** — сумма УПД / актов выполненных работ / актов сдачи-приёмки по договору.
- **Оплачено** — сумма платёжных поручений по договору.
- **Расчёты** = закрыто − оплачено: у доходного договора > 0 — нам должны, у расходного — мы должны; < 0 — аванс.
- Документы без договора группируются по контрагенту и проекту.
